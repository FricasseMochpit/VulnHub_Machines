# So Simple: 1 — отчёт по машине VulnHub

> **Сложность:** Easy  
> **ОС:** Linux  
> **Направление:** WordPress, перечисление, удалённое выполнение команд, SSH, повышение привилегий Linux  
> **Лаборатория:** [So Simple: 1 на VulnHub](https://www.vulnhub.com/entry/so-simple-1,515/)  
> **Подробное прохождение:** [открыть `WRITEUP.md`](./WRITEUP.md) — содержит спойлеры

## Обзор

So Simple: 1 — учебная Linux-машина VulnHub. В ходе работы выполняются обнаружение машины в локальной сети, сканирование сервисов, поиск WordPress, перечисление пользователей и плагинов, эксплуатация уязвимого компонента, получение SSH-доступа и последовательное повышение привилегий до root.

## Навыки и инструменты

- Обнаружение хостов в локальной сети
- Сканирование портов и сервисов
- Перебор веб-директорий
- Перечисление WordPress
- Поиск и применение публичного эксплойта
- Работа с SSH-ключами
- Анализ разрешений `sudo`
- Netdiscover, Nmap, Gobuster, WPScan, Exploit-DB, SSH

## Разведка

Netdiscover использовался для обнаружения целевой машины. Сканирование Nmap выявило SSH на TCP-порту 22 и HTTP на TCP-порту 80. Перебор веб-директорий с помощью Gobuster обнаружил каталог `/wordpress`.

## Перечисление

WPScan обнаружил пользователей `admin` и `max`, а также устаревшие плагины WordPress. Проверка пароля пользователя `max` по словарю завершилась успешно. Для плагина Social Warfare был найден публичный эксплойт.

## Эксплуатация

Запуск эксплойта предоставил командную оболочку от имени `www-data`. В домашнем каталоге пользователя `max` был обнаружен приватный SSH-ключ, после чего удалось установить SSH-соединение от имени этого пользователя.

## Повышение привилегий

Проверка `sudo` показала, что пользователь `max` может без пароля запускать `service` от имени `steven`. После перехода к `steven` была обнаружена возможность выполнить `/opt/tools/server-health.sh` от имени root. Отсутствующий каталог и сценарий удалось создать, после чего запуск разрешённой команды предоставил оболочку root.

## Влияние

Эксплуатация веб-приложения привела к выполнению команд, получению SSH-доступа и полному контролю над операционной системой с правами root.

## Рекомендации

- Своевременно обновлять WordPress и установленные плагины.
- Удалять неиспользуемые и устаревшие компоненты.
- Использовать стойкие пароли и ограничивать попытки входа.
- Не хранить приватные SSH-ключи с избыточными правами доступа.
- Следовать принципу минимальных привилегий при настройке `sudo`.
- Не разрешать привилегированный запуск сценариев из каталогов, доступных для изменения непривилегированным пользователям.

## Отказ от ответственности

Материал описывает действия, выполненные на специально созданной учебной машине VulnHub. Все техники приведены в образовательных целях. Проверка систем без явного разрешения их владельца недопустима.
